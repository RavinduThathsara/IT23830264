# Assignment 1 – Singlish to Sinhala Transliteration Testing

## 📌 Overview

This assignment focuses on testing a Singlish to Sinhala transliteration system using automated and manual testing approaches. The goal is to identify incorrect outputs using negative test cases.

## 🎯 Objective

* Validate transliteration accuracy
* Identify mismatches between expected and actual outputs
* Perform negative testing using diverse input types

## 🧪 Test Approach

* 50 negative test cases were created

* Inputs include:

  * Slang words
  * English mixed sentences
  * Numbers, dates, and currency
  * Emojis and special characters

* Each test case compares:

  * Expected Output vs Actual Output

## ⚙️ Automation

* Python + Playwright used for automation
* Excel file used to store:

  * Input
  * Expected Output
  * Actual Output
  * Status (PASS/FAIL)

## ⚠️ Challenges

* Website API instability (“Failed to fetch” error)
* UI changes affected automation selectors
* Some outputs could not be retrieved automatically

## 🛠️ Solution

* Added fallback logic in script
* Handled errors using:

  * "NO OUTPUT (UI/API ERROR)"
* Manual verification used where necessary

## 📊 Result

* All 50 test cases executed
* Majority resulted in FAIL (as expected for negative testing)
* System limitations identified successfully
